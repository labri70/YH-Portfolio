```text
이 앱은 학습용 EDA 대시보드이며 의학적 진단 도구가 아닙니다. 실제 진단은 의료 전문가의 판단이 필요합니다.
```

## 8. `service_app.py` 기본 뼈대

아래 구조로 시작하면 됩니다.

```python
from pathlib import Path

import matplotlib.pyplot as plt
import pandas as pd
import seaborn as sns
import streamlit as st


BASE_DIR = Path(__file__).resolve().parent
DATA_DIR = BASE_DIR / "data"


st.set_page_config(
    page_title="건강 데이터 EDA 대시보드",
    page_icon="🩺",
    layout="wide",
)


@st.cache_data
def load_heart():
    return pd.read_csv(DATA_DIR / "heart.csv")


@st.cache_data
def load_diabetes():
    return pd.read_csv(DATA_DIR / "diabetes.csv")


def draw_rate_bar(df, x, y, title, xlabel, ylabel):
    fig, ax = plt.subplots(figsize=(7, 4))
    sns.barplot(data=df, x=x, y=y, ax=ax)
    ax.set_title(title)
    ax.set_xlabel(xlabel)
    ax.set_ylabel(ylabel)
    ax.set_ylim(0, 100)
    st.pyplot(fig)


def heart_page():
    st.header("심장병 EDA")
    st.caption("Kaggle Heart Disease Dataset 기반 미니프로젝트 요약 대시보드")

    df = load_heart()
    df_clean = df.drop_duplicates()

    c1, c2, c3 = st.columns(3)
    c1.metric("중복 제거 후 데이터", f"{len(df_clean):,}행")
    c2.metric("심장병 있음 비율", f"{df_clean['target'].mean() * 100:.1f}%")
    c3.metric("컬럼 수", f"{df_clean.shape[1]}개")

    tab1, tab2, tab3 = st.tabs(["데이터 개요", "핵심 시각화", "해석"])

    with tab1:
        st.dataframe(df_clean.head(50))
        st.write(df_clean.describe())

    with tab2:
        cp_rate = (
            df_clean.groupby("cp")["target"]
            .mean()
            .mul(100)
            .reset_index(name="심장병 발병률")
        )
        draw_rate_bar(cp_rate, "cp", "심장병 발병률", "흉통 유형별 심장병 발병률", "흉통 유형(cp)", "발병률(%)")

        sex_rate = (
            df_clean.groupby("sex")["target"]
            .mean()
            .mul(100)
            .reset_index(name="심장병 발병률")
        )
        draw_rate_bar(sex_rate, "sex", "심장병 발병률", "성별 심장병 발병률", "성별(sex)", "발병률(%)")

    with tab3:
        st.markdown(
            """
            - 흉통 유형(`cp`)은 심장병 여부와 강한 관련을 보였습니다.
            - 콜레스테롤 하나만으로 심장병 여부를 설명하기는 어렵습니다.
            - 의료 데이터에서는 실제 환자를 놓치지 않는 recall 관점이 중요합니다.
            """
        )


def diabetes_page():
    st.header("당뇨 EDA")
    st.caption("Kaggle Pima Diabetes Dataset 기반 미니프로젝트 요약 대시보드")

    df = load_diabetes()

    c1, c2, c3 = st.columns(3)
    c1.metric("데이터", f"{len(df):,}행")
    c2.metric("당뇨 양성 비율", f"{df['Outcome'].mean() * 100:.1f}%")
    c3.metric("컬럼 수", f"{df.shape[1]}개")

    tab1, tab2, tab3 = st.tabs(["데이터 개요", "숨은 결측", "주요 변수"])

    with tab1:
        st.dataframe(df.head(50))
        st.write(df.describe())

    with tab2:
        zero_cols = ["Glucose", "BloodPressure", "SkinThickness", "Insulin", "BMI"]
        zero_rate = (
            (df[zero_cols] == 0)
            .mean()
            .mul(100)
            .reset_index()
        )
        zero_rate.columns = ["컬럼", "0값 비율"]
        draw_rate_bar(zero_rate, "컬럼", "0값 비율", "컬럼별 0값 비율", "컬럼", "0값 비율(%)")

    with tab3:
        feature = st.selectbox("비교할 변수", ["Glucose", "BMI", "Age", "Pregnancies"])
        fig, ax = plt.subplots(figsize=(7, 4))
        sns.boxplot(data=df, x="Outcome", y=feature, ax=ax)
        ax.set_title(f"Outcome별 {feature} 분포")
        st.pyplot(fig)

        st.markdown(
            """
            - 당뇨 양성 그룹은 Glucose, BMI, Age 평균이 더 높았습니다.
            - 특히 Glucose는 당뇨 여부와 가장 뚜렷한 차이를 보였습니다.
            - `Insulin`, `SkinThickness`는 0값 비율이 높아 결측 처리 해석이 중요합니다.
            """
        )


def main():
    st.title("건강 데이터 EDA 대시보드")
    st.caption("심장병과 당뇨 미니프로젝트 분석 결과를 온라인 서비스 형태로 정리한 Streamlit 앱")

    menu = st.sidebar.radio("분석 메뉴", ["심장병 EDA", "당뇨 EDA"])

    st.sidebar.markdown("---")
    st.sidebar.caption("교육용 분석 대시보드입니다. 의료 진단 목적으로 사용하지 마세요.")

    if menu == "심장병 EDA":
        heart_page()
    else:
        diabetes_page()


if __name__ == "__main__":
    main()
```

### 10.3 requirements.txt 주의

상위 `Streamlit/requirements.txt`는 ST3/ST4 수업 전체용이라 `torch`, `torchvision`, `transformers`, `openai`까지 포함되어 있습니다.

하지만 `health-eda-streamlit`은 심장병/당뇨 EDA 서비스만 담당하므로, 앱 폴더 안의 `requirements.txt`는 가볍게 따로 만드는 것을 추천합니다.

```text
streamlit==1.59.1
pandas==2.3.3
numpy==2.4.4
scikit-learn==1.9.0
seaborn==0.13.2
matplotlib==3.10.8
```

이렇게 하면 Streamlit Cloud가 불필요한 딥러닝 패키지를 설치하지 않아 배포가 더 빠르고 안정적입니다.

선택지:

```text
빠른 EDA 서비스 배포만 목표: health-eda-streamlit/requirements.txt를 가볍게 작성
수업 전체 앱 보존이 목표: 상위 Streamlit 폴더와 별도 저장소로 분리
```

Streamlit Community Cloud는 Python 의존성을 찾기 위해 보통 repository root 또는 앱 진입 파일과 같은 폴더의 `requirements.txt`를 읽습니다. 따라서 `health-eda-streamlit` 폴더 자체를 GitHub 저장소로 만들면, 그 안의 가벼운 `requirements.txt`가 사용됩니다.
